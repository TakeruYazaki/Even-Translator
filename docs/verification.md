# 0.2.1 検証記録 — 2026-09-10

## 遅延修正

- ユーザーが実機で英語音声の和訳表示を確認。ただし表示が遅いとの報告。
- 古い字幕を4〜12秒ずつ消化する待ち行列を最新追従時に解消。次の訳を即時優先し、全文と未読ページは履歴に保持。
- 確定認識後の最大追加待ちを1800→500ms、Deepgramのendpointingを500→300msに変更。
- 翻訳のキュー待ち/API所要時間を履歴・JSONに追加。STT確定待ちと実機表示遅延は測定対象外。
- 単体/サーバー16件＋ブラウザー5件成功。長い旧字幕が残っていても新しい訳を1秒以内に画面へ反映する回帰テスト、模擬G2更新と手動履歴保持を確認。
- 型検査・ビルド・0.2.1パッケージ作成成功。
- 同じ11.425秒の合成英語を実APIへ送信。修正前の翻訳待ち＋API時間は1230/1192/764ms、修正後は1675/1151/616ms（キュー待ち0ms）。API自体の高速化を示す結果ではなく、今回の主要変更は表示側の不要な待ちの除去。
- 修正後のG2実機での体感遅延と、短い認識区切りによる翻訳品質への影響は未確認。
